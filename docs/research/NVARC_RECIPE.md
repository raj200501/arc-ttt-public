## 2. The recipe (from nvarc_2025.pdf + repo configs)

**Scores:** 27.64% public LB (competition best), **24.03% final private LB** (1st place; per ARC Prize results blog via search snippets); post-deadline variant 29.72% public. ~$0.20/task (NVIDIA blog claim). 1–2 point run-to-run variance.

**Base model: `Qwen3-4B-Thinking-2507`** (exact path in `sft_mg.yaml`); post-deadline 2B variant used the LLM part of `Qwen3-VL-2B-Instruct` (22.22% public, 6h10m runtime vs 12h/29.72% for 4B).

**Synthetic data (the core idea):** 4-stage SDG using claude-opus-4-20250514, claude-sonnet-4-5-20250929, and mostly gpt-oss-120b via NeMo-Skills (15k tok/s on 8×H100). (1) Seed descriptions from H-ARC + 160 BARC descriptions → 716 covered training puzzles; summaries in 5 sections (input generation / solution steps / rules summary / key insight / concepts); plus 29 hand-labeled ARC-AGI-2 eval puzzles used as few-shot seeds to auto-summarize the remaining 91 eval + 1000 training puzzles → 3,268 summaries. (2) INSTRUCT-SKILLMIX-style pairwise mixing → 266,593 new summaries. (3) LLM writes Python input-grid generators + unit tests; keep programs yielding ≥30 unique passing grids (~70%/50% acceptance) → 126,901. (4) LLM writes output-grid programs; keep only self-consistent ones (e.g. 15/20 samples agree on all 30 grids) → **103,253 puzzles, ~30 I/O pairs each**.

**LLM pretraining:** grids serialized as digits in Qwen3 chat template (input grid in `user`, output in `assistant` turns); tokenizer cut to 16 tokens. Mix (Table 1): MINI-ARC 147/ConceptARC 160/RE-ARC 400/ARC-AGI-2 609 puzzles at 256 augs each + NVARC-training 47,337 (24 augs) + NVARC-full 55,886 (32 augs) = 3,255,481 samples. Full SFT via NeMo-RL Megatron backend: **4 nodes × 8 H100, 27 h**; lr 3e-5 (linear decay to 3e-7, adam β=(0.9,0.98), wd 0.1, clip 1.0), bf16, global batch 8, sequence packing 128k tokens/micro-batch (paper says packs up to 256k tokens/256 examples), TP=8, CP=2, max 10k steps/5 epochs.

**TTT (per task, in the 12h notebook):** LoRA per-puzzle, **r=256, alpha=32** (2024 harness in repo also shows: rslora, lr 5e-5, 1 epoch, warmup_ratio 0.1, batch 1, 16 augmented copies of the demos, `shfl_keys=True`), bf16, no gradient checkpointing, no 4-bit quant, Unsloth + FlashAttention-2, 4 GPU workers each pinned to one L4 with a task queue.

**Decoding/selection:** batched depth-first search over output tokens with probability cutoff (max_score = −log 0.2 in the ARC-AGI-1 harness); candidates re-scored under **8 augmentations, identical augmentation set for every candidate**; final selection score = (# times candidate found in DFS) + geometric-mean (mean log-prob over the m=8 augmentations) — formula in §3.4. They tried Thinking Machines' `batch_invariant_ops` for determinism (better validation, 17% slower — not used). **TRM ensemble:** improved TRM (repo cmd: L_layers=2, H_cycles=3, L_cycles=4, EMA, lr 3e-4, batch 3072, 10k epochs, 24 h on 8×H100 pretraining; TTT on Kaggle 2000 epochs, 200 warmup, H_cycles=4, halt_max_steps=10, ~2 h, embedding table re-initialized to mean) generates 10 attempts/puzzle, re-scored by the Qwen3 model. Selected submission was Qwen3-2B+TRM (20.28 public) but the pure Qwen3-4B run was better (27.22 in 10 h); TRM alone: 7.5%, later 10.0%.

## 3. Runner-ups

- **2nd, the ARChitects — 16.53%.** Report: https://lambdalabsml.github.io/ARC2025_Solution_by_the_ARChitects/ ; code: https://github.com/LambdaLabsML/ARC2025_Solution_by_the_ARChitects (created 2025-12-05). Recipe (from report snippets — page itself blocked): abandoned their 2024 autoregressive Qwen approach for a **masked-diffusion LLM (LLaDA-8B)** with 2D-aware positional encoding modified for grids, recursive self-refinement at inference, and their "matter of perspective" product-of-experts/perspective-based scoring (background: da-fr/arc-prize-2024 and da-fr/Product-of-Experts-ARC-Paper, ICML 2025).
- **3rd, MindsAI/Tufa Labs — 12.64% private** (the 15.42% figure appears in the ARC Prize blurb; discrepancy unresolved — likely public vs private LB). Code: https://github.com/jcole75/arc_2025_mindsai (MIT). Recipe: **CodeT5-based encoder-decoder models** (codet5_660m / "salesforce_codet5_large_arcmega") pretrained on HF dataset `mindware/arc-agi-mega`, Jack Cole's TTT + AIRV (augmented inference with reverse-augmentation voting), tokenizer dropout, augmentation ensembles. Writeup: kaggle.com/competitions/arc-prize-2025/writeups/mindsai-and-tufa-labs-arc-prize-2025-solution (blocked).

## 4. Compute envelope

Kaggle limit (paper §1): **12 h on 4×L4 (24 GB each) for 240 hidden tasks**, one submission/day. NVARC offline: SDG on 1×8×H100 (gpt-oss-120b, NeMo-Skills); LLM SFT 32×H100 for 27 h (~864 H100-hours); TRM pretrain 8×H100 for 24 h. Inference used essentially the full 12 h (2B: 6h10m; 4B-10h variant scored 27.22). TRM portion of the ensemble budget: ~2 h.
