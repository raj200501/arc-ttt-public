How to read this


17 of these 30 documents are ties, twelve of them perfect on both sides. Where in-context prompting already works, adaptation adds nothing — and on five documents it costs a field. That is visible above and it is not hidden here.


The gap is concentrated. Roughly 63% of the total delta comes from three documents where the prompted model returned no valid JSON at all and scored zero. The clearest cases — m-2201 is the one to look at — are not about extracting better. The prompted model reads the document correctly and then answers in a schema it invented: carrier_name, trailer_weight, pickup_location. The adapted model returns the tenant's eight fields, in the tenant's spelling, normalized the tenant's way.


So the honest claim from this run is schema conformance, not accuracy. On a real pipeline that distinction matters more than it sounds: a wrong value is a data-quality problem, and an invented key is an outage.


This corpus was authored by an adversarial AI agent that we operated ourselves, on the same host, with the gold labels withheld in process and hash-committed before submission. That is procedural blindness, not third-party custody — it is a transfer signal, not a customer result. The standing offer to run this on documents we have never seen is open, and the terms are published.
